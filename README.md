# Library Sequence Diagrams

## About
This project describes the internal interactions of the Library Reservation System using UML sequence diagrams.

## Purpose
The purpose is to detail the execution of the use case **UC-01: Reserve a Book Copy**.

## Scenarios
The project includes sequence diagrams for:
- SC-01: Successful reservation
- SC-02: No available book copies
- SC-03: Selected book copy is already reserved

## Project Structure
- `sequence/` — sequence diagram source files and rendered diagrams.
- `audit/` — consistency audit.
- `ai/` — AI usage log.
- `spec.md` — scenario and participant specification.
- `DEFENSE.md` — project defense.

## Modeling Tool
Mermaid `sequenceDiagram` syntax.
